# Party flag assets

Add party flag images to this folder as PNG files.

File names are generated from the party name returned by the API:
- Lowercase the party name.
- Replace spaces and punctuation with hyphens.
- Remove leading or trailing hyphens.
- Use the `.png` extension.

Examples:

- `CPI(M)` -> `cpi-m.png`
- `INC` -> `inc.png`
- `IUML` -> `iuml.png`
- `KEC(J)` -> `kec-j.png`
- `BJP` -> `bjp.png`
