# openMinistry

A civic-tech platform that collects, indexes, and publishes public statements
made by ministers and representatives in the Government of Kerala (for now).

## Purpose

Improve political transparency by creating a searchable public archive of
statements from newspapers, interviews, press conferences, and public media.

## Status

🚧 Active development

## Stack

- Frontend: Next.js + Tailwind CSS
- Backend: Python + FastAPI
- Database: PostgreSQL
- Queue: Redis + Celery
- Scraping: Playwright + BeautifulSoup
